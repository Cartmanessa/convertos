# ConvertOS

Учебная 32-битная операционная система для x86. Загрузчик на ассемблере FASM переводит процессор в защищённый режим и загружает ядро на C++, которое работает без стандартной библиотеки и ОС: собственный вывод на экран, обработка прерываний и драйвер клавиатуры. Поверх ядра работает командная строка с конвертерами систем счисления и времени.

Учебный проект (СПбПУ, Высшая школа кибербезопасности).

## Возможности

- Загрузчик в одном загрузочном секторе (512 байт): меню выбора цвета текста стрелками, загрузка ядра с дискеты, включение линии A20, GDT, переход в защищённый режим.
- Ядро на C++ (компилятор MSVC) со вставками ассемблера: работа с портами ввода-вывода, таблица прерываний IDT, обработчик клавиатуры (IRQ1) со скан-кодами и Shift, текстовый режим VGA с прокруткой экрана и аппаратным курсором.
- Командная строка с приглашением `# `.

## Команды

| Команда | Действие |
| --- | --- |
| `info` | сведения о системе и выбранном цвете загрузчика |
| `clear` | очистить экран |
| `shutdown` | выключить виртуальную машину |
| `nsconv <число> <из> <в>` | перевести число из одной системы счисления в другую (основания от 2 до 36, цифры выше 9 записываются буквами) |
| `posixtime <секунды>` | преобразовать время POSIX (секунды с 01.01.1970) в дату `ДД.ММ.ГГГГ чч:мм:сс` |
| `wintime <число>` | преобразовать время Windows FILETIME (интервалы по 100 нс с 01.01.1601) в дату |

Допустимые при вводе символы: латинские буквы, цифры, `+`, `-`, `*`, `/` и пробел. Длина команды не больше 40 символов.

### Примеры

```
# nsconv ff 16 2
11111111
# nsconv 255 10 16
ff
# posixtime 1700000000
14.11.2023 22:13:20
# wintime 133000000000000000
18.06.2022 04:26:40
```

`posixtime` принимает числа до 4294967295 (до 07.02.2106). `nsconv` работает с числами до 32 бит.

## Как это устроено

**Загрузка.** BIOS загружает первый сектор по адресу `0x7C00`. Загрузчик показывает меню цвета и сохраняет выбранный атрибут цвета в байт `0x1000`, откуда его потом читает ядро. Затем он читает ядро со второй дискеты (`-fdb`): 15 секторов с адресом назначения `0x11000` и ещё 7 секторов по адресу `0x13000`. Так секции PE-файла ядра (код и данные) оказываются в памяти по тем адресам, которые заданы при компоновке: база образа `0x10000`, выравнивание файла 512 байт. После этого загрузчик включает A20, загружает GDT с плоскими сегментами кода и данных, включает защищённый режим и вызывает `0x11000`.

**Ядро.** По адресу `0x11000` находится начало секции кода, где лежит функция `startup()`: она вызывает `kmain()`. Поэтому `startup()` должна оставаться первой функцией в `kernel.cpp`. `kmain()` читает цвет, очищает экран, создаёт таблицу прерываний (по умолчанию все 256 векторов указывают на заглушку), регистрирует обработчик клавиатуры на вектор `0x09`, размаскирует только IRQ1 в контроллере 8259 и входит в цикл `hlt`.

**Ввод.** Обработчик клавиатуры читает скан-код из порта `0x60`, переводит его в символ по таблице (отдельная для Shift), накапливает команду в буфере и по Enter передаёт её в `functional()`, которая разбирает строку на слова и вызывает нужную команду.

**Арифметика без стандартной библиотеки.** Системы счисления перебираются схемой Горнера. Для `wintime` число до 20 цифр хранится как строка: она делится на 10 000 000 (получаются секунды с 1601 года), затем из неё вычитается 11 644 473 600 (смещение до 1970 года), и результат переводится в календарную дату тем же кодом, что и `posixtime`.

## Сборка и запуск (Windows)

Нужны:

- [FASM](https://flatassembler.net/) для загрузчика;
- компилятор и компоновщик Microsoft (`cl.exe`, `link.exe`): запускайте команды из «Командной строки разработчика» Visual Studio;
- [QEMU](https://www.qemu.org/) для запуска. В `run.bat` предполагается путь `C:\Program Files\qemu\`, при другом пути отредактируйте файл.

```
build.bat
run.bat
```

`build.bat` выполняет три шага: собирает загрузчик в `bootsect.bin`, компилирует `kernel.cpp` в `kernel.obj` и собирает из него `kernel.bin`. `run.bat` запускает QEMU с `bootsect.bin` в первой дискете и `kernel.bin` во второй.

В начале работы загрузчик предложит выбрать цвет: стрелки вверх и вниз меняют вариант, Enter подтверждает.

## Известные ограничения

- В меню цвета стрелка вниз на первом цвете (серый) не переходит к последнему, а выбирает неверное значение.
- Backspace стирает и приглашение `# `, и при пустой команде может записать данные за пределы буфера команды.
- Shift действует только на один следующий символ, даже если клавиша удерживается.
- `wintime` для очень малых чисел (дата до 1970) не выводит ошибку, а показывает 01.01.1970.
- Загрузчик не проверяет ошибки чтения диска и ожидает ядро строго на второй дискете.
- Команда `info` при неизвестном значении цвета обращается к неинициализированной переменной.

## Чему научился

- Писать загрузчик: BIOS-прерывания, GDT, переход из реального режима в защищённый.
- Собирать ядро без стандартной библиотеки и ОС: задавать адрес загрузки и точку входа при компоновке PE-файла.
- Работать с прерываниями на x86: IDT, шлюзы прерываний, контроллер 8259, EOI.
- Писать драйвер клавиатуры и вывод через видеопамять VGA.
- Реализовывать арифметику и календарные преобразования без готовых библиотек, включая вычисления над длинными числами в строках.
